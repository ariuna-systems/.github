# ARIUNA

ARIUNA is a technology startup focused on developing situational awareness platforms for regulated industries.

We don’t ride on hype — we ride on discipline. In a world obsessed with the next big thing, we stay grounded. 
No buzzwords. No shortcuts. Just hard work, clarity, and long-term impact.

Our Philosophy: **Move Fast, Break Nothing**

## What We Do

We build reliable and performant **situational awareness** platform with a focus on **stream processing**, **formal verification** and **deterministic execution**.

## What We Use

- **C++** and/or **Rust** for performance-critical components  
- **Haskell/Common Lisp + Coalton** for robust logic and semantic modeling  
- **JavaScript** for custom UI and data visualizations  
- **Python** for data integration, scripting, and prototyping
